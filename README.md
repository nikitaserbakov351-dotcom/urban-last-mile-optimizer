# ?? Last Mile Optimizer

## Описание проекта
**Last Mile Optimizer** — это специализированная система для оптимизации доставки товаров на «последней миле». Проект разработан для демонстрации навыков в области транспортной логистики, проектирования баз данных и Fullstack-разработки на Python.

## Технологический стек
- **Backend:** Python 3.10+, FastAPI (высокопроизводительный асинхронный фреймворк)
- **База данных:** SQLite (через SQLAlchemy ORM)
- **Frontend:** HTML5, CSS3 (Modern UI), JavaScript (ES6+)
- **Визуализация:** Leaflet.js (интерактивные карты)
- **Алгоритмы:** Жадный поиск ближайшего соседа (Nearest Neighbor), формула Гаверсинуса для расчета гео-расстояний.

## Основной функционал
1. **Управление заказами:** Хранение координат, веса и временных окон доставки.
2. **Управление автопарком:** Контроль грузоподъемности и статусов транспортных средств.
3. **Оптимизация маршрутов:** Автоматическое распределение заказов между доступными машинами с минимизацией общего пробега.
4. **Интерактивный мониторинг:** Визуализация расположения склада и заказов на карте в реальном времени.

## Как запустить проект локально
1. Установите зависимости:
   `ash
   pip install fastapi uvicorn sqlalchemy
   `
2. Инициализируйте базу данных:
   `ash
   python database.py
   `
3. Запустите сервер:
   `ash
   uvicorn app.main:app --reload
   `
4. Откройте браузер: http://127.0.0.1:8000

## Математическое обоснование
В проекте используется расчет расстояния между двумя точками на сфере (Земле) по формуле Гаверсинуса:
 = 2R \cdot \arcsin\left(\sqrt{\sin^2\left(\frac{\Delta\phi}{2}\right) + \cos\phi_1\cos\phi_2\sin^2\left(\frac{\Delta\lambda}{2}\right)}\right)$
где $\phi$ — широта, $\lambda$ — долгота.
